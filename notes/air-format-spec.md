# Springer Nature / Artificial Intelligence Review — LaTeX Formatting Specification

**Source of truth.** This spec is derived from, and cross-checked against:
- `AIR_Journal_Template/sn-article-template/user-manual.pdf` (full text extracted to `notes/_user_manual.txt`, 14 pages, "Springer Nature — User Manual — Journal article LaTeX authoring template", Version 3.1 December 2024).
- `AIR_Journal_Template/sn-article-template/sn-article.tex` (annotated sample article).
- `AIR_Journal_Template/sn-article-template/sn-jnl.cls` (class file; line endings are CR-only, so line numbers below are 1-based after normalizing `\r` to newlines).
- `AIR_Journal_Template/sn-article-template/bst/sn-basic.bst` (bibliography style).
- `AIR_Journal_Template/sn-article-template/sn-bibliography.bib` (sample bib).

Any conflict between journal-level instructions and this universal template is resolved in favour of the journal-level instructions (the manual states this explicitly).

## 1. Reference style decision — REQUIRED: Springer Basic, NUMERIC / numbered

### 1.1 Assignment requirement
The assignment requires **Springer Basic (numeric, brackets `[1]`, `[1,2]`, `[1-3]`)** style.

Per the manual (§7.9 and §8.3 table), the "Basic Springer Nature Reference Style / Chemistry Reference Style" corresponds to the **`sn-basic`** option and the **`bst/sn-basic.bst`** file. The sample `.tex` line 26/32 labels it: `% Basic Springer Nature Reference Style/Chemistry Reference Style -> sn-basic.bst`.

### 1.2 How the class selects numeric vs author-year
The class defines a single switch for that (cls lines 70–71, 107, 117):

```
\newif\if@Numbered@refstyle\global\@Numbered@refstylefalse% Namedate
\newif\if@Spr@basic@refstyle\global\@Spr@basic@refstylefalse% 1.Basic Springer Nature Reference Style/Chemistry Reference Style -> sn-basic.bst
...
\DeclareOption{sn-basic}{\global\@Spr@basic@refstyletrue}%
...
\DeclareOption{Numbered}{\global\@Numbered@refstyletrue}%
```

The exact class behaviour for the Basic branch (cls lines 1647–1659):

```
\if@Spr@basic@refstyle%
\if@Numbered@refstyle%
  \usepackage[numbers,sort&compress]{natbib}%
  \gdef\NumBib{YES}%
\else%
 \usepackage[authoryear]{natbib}%
  \setcitestyle{aysep={}}
  \gdef\NumBib{NO}%
\fi%
  \bibliographystyle{sn-basic}%
  \setlength{\bibsep}{1em}%
  \def\bibfont{\reset@font\fontfamily{\rmdefault}\normalsize\selectfont}%
\fi%
```

**Consequences (verified against the class file):**
- `sn-basic` **alone** ⇒ author-year (`natbib[authoryear]`), `\setcitestyle{aysep={}}` (so the output is `(Jones et al. 1990)` — comma/`aysep` removed).
- `sn-basic,Numbered` ⇒ numeric: `natbib[numbers,sort&compress]` with `\bibliographystyle{sn-basic}` already injected by the class. **No superscript option (`super`) is used anywhere** — citations render as bracket numbers `[1]`, and `sort&compress` collapses runs to `[1-3]`.

The manual §7.9 states the switch explicitly:
> "you can switch for 'sn-basic' and 'sn-chicago' between the options by adding or removing "Numbered" in the \documentclass line of the sn-article.tex file.
> For example: `\documentclass[sn-basic,Numbered]{sn-jnl}`
> For author-year citation style: `\documentclass[sn-basic]{sn-jnl}`"

### 1.3 EXACT recommended preamble (copy verbatim)

```latex
\documentclass[pdflatex,sn-basic,Numbered]{sn-jnl}
```

Notes:
- `pdflatex` is loaded as the default by the class since v3.1 (manual change history; sample `.tex` line 23). It is harmless to omit, but including it matches the template's own examples (`.tex` line 32).
- `\bibliographystyle{sn-basic}` is injected **automatically** by `sn-jnl.cls`, so you do **not** need to type it. If you include it manually it is harmless and matches the result.
- The bst file must be present: "extract the corresponding `sn-basic.bst` file from the bst folder and place it in the same folder as the `sn-article.tex` file" (manual §8.3). In this repo it is at `AIR_Journal_Template/sn-article-template/bst/sn-basic.bst`.
- Reference list is generated by BibTeX. The manual requires the bibliographic file to be placed **in the same directory as the manuscript (no subfolders)**, and BibTeX run order: "run LaTeX on your manuscript file once, followed by BibTeX, and then run LaTeX twice" (manual §8.3).

**Preamble / bibliography lines:**
```latex
\usepackage{graphicx}% standard, provided by class dependency list
% (amsmath, amssymb, amsfonts, mathrsfs, rotating, appendix, textcomp, manyfoot,
%  booktabs, algorithm, xcolor, algorithmicx, algpseudocode, listings, url are all
%  loaded/required by sn-jnl.cls; do not re-add unnecessarily — see §9 below)

...

\bibliography{<bib-file-without-extension>}   % REQUIRED; place after \backmatter, before \end{document}
```
The sample uses `\bibliography{sn-bibliography}` (sample `.tex` line 619). Do **not** use `\input{...}` to include other `.tex` files ("Please do not use `\input{...}` to include other tex files. Submit your LaTeX manuscript as one .tex document." — `sn-article.tex` lines 6–7).

## 2. Front matter skeleton (exact syntax)

Placement rules (manual §5): everything **before** `\maketitle` is *front matter*; everything after it but before `\backmatter` is *main matter*; everything after `\backmatter` is *back matter*.

```latex
\title[Short running title]{Full Article Title}

%% GivenName -> \fnm{...}
%% Particle   -> \spfx{...}  (surname prefix)
%% FamilyName -> \sur{...}
%% Suffix     -> \sfx{...}
\author*[1,2]{\fnm{First} \sur{Author}}\email{iauthor@gmail.com}

\author[2,3]{\fnm{Second} \sur{Author}}\email{iiauthor@gmail.com}
\equalcont{These authors contributed equally to this work.}

\author[1,2]{\fnm{Third} \sur{Author}}\email{iiiauthor@gmail.com}
\equalcont{These authors contributed equally to this work.}

\affil*[1]{\orgdiv{Department}, \orgname{Organization},
  \orgaddress{\street{Street}, \city{City}, \postcode{100190}, \state{State}, \country{Country}}}

\affil[2]{\orgdiv{Department}, \orgname{Organization},
  \orgaddress{\street{Street}, \city{City}, \postcode{10587}, \state{State}, \country{Country}}}

\affil[3]{\orgdiv{Department}, \orgname{Organization},
  \orgaddress{\street{Street}, \city{City}, \postcode{610101}, \state{State}, \country{Country}}}

\abstract{The abstract serves both as a general introduction to the topic and as a brief,
non-technical summary of the main results and their implications. Authors are advised to check
the author instructions for the journal they are submitting to for word limits and if structural
elements like subheadings, citations, or equations are permitted.}

\keywords{keyword1, Keyword2, Keyword3, Keyword4}

\maketitle
```

**Rules extracted from manual §6:**
1. `\title[<short-form-of-article-title>]{<article-title>}` — optional short form first, `{<article-title>}` is mandatory. Example: `\title[Article Title]{Article Title}`.
2. `\author*[<affil-num>]{<author-name>}` — the **corresponding author** (responsible through the publication process). `\author[<affil-num>]{<author-name>}` — all other authors.
3. `\affil[<sequence>]{<address-details>}` — affiliation. "In case of multiple addresses, just provide sequential Arabic numerals in the optional argument of this tag. ... In case of single author/address, this optional argument can be ignored."
4. `\affil*[<sequence>]{<address-details>}` — the author's **present/corresponding address**.
5. Other common front-matter tags: `\email{...}` `\nomail` `\orgdiv{...}` `\orgname{...}` `\street{...}` `\city{...}` `\state{...}` `\country{...}` `\orgaddress{...}` `\postcode{...}` `\equalcont{...}` `\abstract{...}` `\keywords{...}` `\received{...}`. 
   - `\nomail` — provide for an author without an email id.
   - `\pacs` — one of the keyword groups (optional; sample shows `\pacs[JEL Classification]{...}` and `\pacs[MSC Classification]{...}`).
6. `\maketitle` is **mandatory** to print the front matter.

**Abstract:** the template shows two variants (sample `.tex` lines 118–134): unstructured (`\abstract{...}`) and structured (with `\textbf{Purpose:}` … `\textbf{Methods:}` … `\textbf{Results:}` … `\textbf{Conclusion:}`). The manual does not impose a hard word limit.

**Keywords:** set with `\keywords{keyword1, Keyword2, ...}`; the class prints the bold head `Keywords:` (cls line 645: `\def\keywords#1{...{\keywordfont{\bfseries\keywordname:} #1\par}}`). The manual does not state a keyword count limit; the sample shows four.

**Subtitle:** the class supports `\subtitle{...}` as a front-matter tag (manual §5 front-matter table).

## 3. Main matter elements

### 3.1 Section headings (manual §7.1)
Three levels, all numbered and bold by default:
```latex
\section{<First level heading>}        % numbered, bold
\subsection{<Second level heading>}    % numbered, smaller bold
\subsubsection{<Third level heading>}  % numbered, further smaller bold
```
To use **unnumbered** level heads, issue `\unnumbered` in the preamble (manual §7.1; clsdepth set to 0: `\def\unnumbered{\setcounter{secnumdepth}{0}}%`, cls line 878). The sample has it commented: `%%\unnumbered% uncomment this for unnumbered level heads`.

Typical/expected section order in the sample: Introduction, Results, implied structure, Equations, Tables, Figures, Algorithms/Program codes/Listings, Cross referencing, theorem examples, Methods, Discussion, Conclusion (sample `.tex` lines 144–533). Note the guidance: "The introduction should not include subheadings"; "Discussion" and "Conclusion" may be interchangeable depending on discipline.

### 3.2 Lists (manual §7.4)
```latex
\begin{enumerate}...\end{enumerate}   % numbered: 1st level Arabic, 2nd lowercase alpha, 3rd lowercase roman
\begin{unenumerate}...\end{unenumerate} % unnumbered
\begin{itemize}...\end{itemize}       % custom/bulleted: 1st bulleted, 2nd dash
```
Nested lists are allowed for numbered and custom lists. `unenumerate` is a class-provided environment.

### 3.3 Theorem-like environments (manual §7.5; cls lines 1588–1629)
Three predefined styles and a `proof` environment:
| Style | Output |
|---|---|
| `thmstyleone` | Numbered, theorem **head bold**, theorem **text italic** |
| `thmstyletwo` | Numbered, theorem **head roman**, theorem **text italic** |
| `thmstylethree` | Numbered, theorem **head bold**, theorem **text roman** |

Define new theorems in the preamble, e.g.:
```latex
\theoremstyle{thmstyletwo}
\newtheorem{proposition}{Proposition}
```
Sample declarations (sample `.tex` lines 74–86):
```latex
\theoremstyle{thmstyleone}%
\newtheorem{theorem}{Theorem}%     continuous numbers; use [section] arg for sectionwise
\newtheorem{proposition}[theorem]{Proposition}%
\theoremstyle{thmstyletwo}%
\newtheorem{example}{Example}%
\newtheorem{remark}{Remark}%
\theoremstyle{thmstylethree}%
\newtheorem{definition}{Definition}%
```
Predefined proof environment: `\begin{proof}...\end{proof}` (prints "Proof" head in italic, body roman, open square at end). `amsthm` is now loaded by the class itself (manual change history v3.1).

### 3.4 Footnotes (manual §7.6)
Standard `\footnote{<Some text>}`. (Nature Portfolio submissions must not use footnotes; Springer Nature journals otherwise allow them.)

### 3.5 Algorithms / code / listings (manual §7.7)
```latex
\begin{algorithm}
\caption{<alg-caption>}\label{<alg-label>}
\begin{algorithmic}[1]
...
\end{algorithmic}
\end{algorithm}
```
`algorithm`, `algorithmicx`, `algpseudocode` packages are required. For code: `\begin{verbatim}...\end{verbatim}` (verbatim) or `\begin{lstlisting}...\end{lstlisting}` (requires the `listings` package).

### 3.6 Equations (manual §7.2; sample §Equations)
Inline: `$...$`. Display with auto-numbering: `equation` or `align` environments, e.g.
```latex
\begin{equation}
 ... \label{eq1}
\end{equation}

\begin{align}
D_\mu &= ... \nonumber \\
F^a_{\mu\nu} &= ... \label{eq2}
\end{align}
```
"Do not use manual skips to align an equation." Use `\nonumber` on all lines of `align` except the last; put `\label{}` only on the last (numbered) line. Class supports `\mathbb{}`, `\mathscr{}`, `\mathcal{}`.

### 3.7 Cross-references (manual §7.8)
`\label{...}` identifies an object (equation, figure, table, algorithm line); `\ref{...}` inserts a clickable link to it. For figures/tables, put `\label` inside or just below `\caption`. Reference style in text: `Figure~\ref{fig1}`, `Table~\ref{tab3}`, `line~\ref{algln2} of Algorithm~\ref{algo1}`.

### 3.8 Citations (manual §7.9)
- `\citep{...}` — parenthetical, e.g. `(Jones et al. 1990)`.
- `\cite{...}` — textual, e.g. `Jones et al. (1990)`.
- With `Numbered` these become bracket numerals: `[1]`, and with `sort&compress`, `[1,2]` / `[1-3]`.

## 4. Figures and Tables (manual §7.3; cls; sample)

### 4.1 Figures
```latex
\begin{figure}[t]
\centering
\includegraphics{<image-file-name>}
\caption{<Caption text>}\label{...}
\end{figure}
```
Rules:
- Use `graphicx`/`\includegraphics`. **Do not place image files in subfolders** — "the manuscript submission system will be unable to find them. Include them on the same level as your LaTeX document."
- **Each figure must be from a single input image file. Avoid subfigures.**
- LaTeX compiler accepts **.eps**; if you have .ps, rename to .eps. For **PDFLaTeX** (the default here) use **pdf/jpg/png** images. The sample figure uses `\includegraphics[width=0.9\textwidth]{fig.eps}` and notes: "the width in the optional argument … [is] for sample purpose … Please ignore this."
- Single-column: `figure`. For spanned (double-column-width) figures: `\begin{figure*}...\end{figure*}`.
- Placement specifiers (`[t]`, `[h]`, etc.) are standard float placement; the sample uses `[h]` and `[t]`.

### 4.2 Tables
```latex
\begin{table}[<float-position>]
\caption{...}\label{<table-label>}
\begin{tabular}{<column-alignment-preamble>}
\toprule
... & ... & ... & ... \\
\midrule
... & ... & ... & ...\footnotemark[1] \\
...
\botrule
\end{tabular}
\footnotetext{...}
\footnotetext[1]{...}
\end{table}
```
- Use **booktabs** rules: `\toprule` / `\midrule` / `\botrule` (note the class/bst convention uses `\botrule`, not `\bottomrule`). `booktabs` is loaded by the class.
- Table footnotes: `\footnotemark[...]` inside the body and `\footnotetext[...]{...}` after `\end{tabular}` but inside the table environment.
- **Wide tables:** in double-column layout, tables that do not fit one column must span the full text width using `\begin{table*}...\end{table*}`. Tables that do not fit `\textwidth` should be **rotated**: `\begin{sidewaystable}...\end{sidewaystable}`; for rotated tables at double-column width use `\begin{sidewaystable*}...\end{sidewaystable*}`.
- For tables wider than text width, the sample uses `\begin{tabular*}{\textwidth}{@{\extracolsep\fill}...}`; for sidewaystable, `\begin{tabular*}{\textheight}{@{\extracolsep\fill}...}`.

**Caption/placement rules stated:** the manual says do not use `\break`, `\pagebreak`, `\vspace`, `\bigskip`, `\clearpage` for fine-tuning — "the use of fine-tuning commands … are not encouraged. Please use semantic mark-up as far as possible and avoid additional formatting commands." (manual §2.1). Caption `\label` must immediately follow (inside/below) the `\caption`.

## 5. Back matter (manual §8)

### 5.1 Headings in back matter
Use `\bmhead{...}` for all back-matter heads placed below `\backmatter`. (Class: `\newcommand\bmhead{\@startsection{subparagraph}{5}...}` with `bmheadfont`.)

### 5.2 Appendices / Extended Data / Supplementary Information (manual §8.2)
```latex
\begin{appendices}
\section{Section title of first appendix}\label{secA1}
...
\end{appendices}
```
All other commands (section heads, tables, figures) remain the same inside. For Nature Portfolio submissions the heading is "Extended Data".

### 5.3 Declarations — exact structure the template expects (sample `.tex` lines 535–588)
The sample places these after `\backmatter`, with `\bmhead{...}` for the two main heads and a `\section*{Declarations}` whose required subsections are listed as itemize entries:

```latex
\backmatter

\bmhead{Supplementary information}
... statement about accompanying supplementary files ...

\bmhead{Acknowledgements}
... brief; grant or contribution numbers may be acknowledged ...

\section*{Declarations}
... check the journal's Instructions for Authors ...

\begin{itemize}
\item Funding
\item Conflict of interest/Competing interests (check journal-specific guidelines for which heading to use)
\item Ethics approval and consent to participate
\item Consent for publication
\item Data availability
\item Materials availability
\item Code availability
\item Author contribution
\end{itemize}

... If any of the sections are not relevant to your manuscript, please include the heading
and write `Not applicable' for that section.
```

**The exact Declarations subsection list (verbatim from the template):**
1. Funding
2. Conflict of interest/Competing interests (check journal-specific guidelines for which heading to use)
3. Ethics approval and consent to participate
4. Consent for publication
5. Data availability
6. Materials availability
7. Code availability
8. Author contribution

The manual does not itself enumerate the Declarations subsections beyond this; the authoritative list is the one in `sn-article.tex`. Note the template states: include the heading and write `Not applicable` for any not-relevant section.

The manual/sample also place ethical-approval statements (Approval / Accordance / Informed consent) **inside the Methods section** where applicable (sample `.tex` lines 509–523).

### 5.4 References (manual §8.3)
- BibTeX is the preferred format. Content lives in a `.bib`; presentation via a `.bst`.
- Bib file must sit in the same directory as the manuscript.
- For Springer Basic: option `sn-basic` + file `bst/sn-basic.bst`. With `Numbered` the reference list is ordered by citation/number; without it, it is author-year.
- Generate `.bbl`: "run LaTeX on your manuscript file once, followed by BibTeX, and then run LaTeX twice."

## 6. Required bibliography entry formats under `sn-basic` (Springer Basic)

> The manual itself does **not** print a rendered "References" example list for the Basic style; it points you to the sample `.bib` and the `.bst` files. The canonical input examples below are quoted verbatim from `sn-bibliography.bib`, and the rendered shapes are derived from the `sn-basic.bst` entry functions (`FUNCTION {article}`, `{book}`, `{incollection}`, `{inproceedings}`, `{misc}`, lines 1180–1412). Fields always emitted where present: authors, year, title, then venue/publisher, then DOI (`format.doi`), URL (`format.url`), note (`format.note`), eprint.

```bibtex

  title			= "The index of general nonlinear {D}{A}{E}{S}",
  journal		= "Numer. {M}ath.",
  volume		= "72",
  number		= "2",
  pages			= "173--196",
  year			= "1995"

```
Journal article with DOI (verbatim):
```bibtex
@article{bib2,
  author		= "Slifka, M. K. and Whitton, J. L.",
  title			= "Clinical implications of dysregulated cytokine production",
  journal		= "J. {M}ol. {M}ed.",
  volume		= "78",
  pages			= "74--80",
```

```bibtex
  title			= "Global integrated drought monitoring and prediction system (GIDMaPS) data sets",

```
Preprint (verbatim):
```bibtex
@misc{bib10, 
  author		= "Babichev, S. A. and Ries, J. and Lvovsky, A. I.",
```

## 7. Hard limits / structural rules and explicit "not stated" items

Facts **stated** in the manual/template:
- **Abstract:** guidance only — "As a guide the abstract should not exceed 200 words. Most journals do not set a hard limit however authors are advised to check the author instructions for the journal they are submitting to." The abstract "must not include subheadings (unless expressly permitted in the journal's Instructions to Authors), equations or citations." (sample `.tex` lines 128–134). **No hard limit is imposed by the template.**
- **Keywords:** no count limit stated; sample shows 4.
- **Figures:** each figure from a single image file; no subfigures; image files at top level (no subfolders); use one image file per figure. **No numeric limit on figure/table count is stated in the manual.**
- **Single .tex document:** "Please do not use `\input{...}` to include other tex files. Submit your LaTeX manuscript as one .tex document. All additional figures and files should be attached separately and not embedded in the `\TeX` document itself." (sample header lines 6–11).
- **No custom fonts:** "Please refrain from using custom fonts." (manual §3.2).
- **No extra packages:** "Wherever possible please do not add further packages to the template." (manual §1); "We recommend avoiding the introduction of any unnecessary formatting" (manual §1).
- **No fine-tuning layout commands:** `\break`, `\pagebreak`, `\vspace`, `\bigskip`, `\clearpage` are not encouraged (manual §2.1).
- **Do not place images in subfolders** (manual §7.3).
- **Line spacing:** single by default; use `[referee]` for double line spacing during peer review; `[lineno]` for margin line numbers (manual §2.1).
- **Double-column layout:** `[iicol]` option → `\documentclass[iicol]{...}` (manual §2.1). The default sample template is single-column.

Items **NOT stated** in the manual/template (do not assume):
- No explicit page limit, figure/table count limit, reference count limit, or total word count is given by the template. Journal-level instructions must be checked.
- No explicit number of keyword limit.
- Concrete reference-style rendered examples for the Basic style are **not printed in the manual**; only the sample `.bib` inputs and the `.bst` are authoritative.

## 8. Available class options (from `sn-jnl.cls` `\DeclareOption`s, lines 82–117)

| Option | Effect |
|---|---|
| `sn-basic` | Basic Springer Nature / Chemistry ref style → `sn-basic.bst` |
| `sn-mathphys-num` / `sn-mathphys-ay` | Math & Physical Sciences numbered / author-year |
| `sn-aps` | American Physical Society |
| `sn-vancouver-num` / `sn-vancouver-ay` | Vancouver numbered / author-year |
| `sn-apa` | APA |
| `sn-chicago` | Chicago-based Humanities |
| `sn-nature` | Nature Portfolio |
| `Numbered` | Selects numeric citation/ref mode for styles that support both (sn-basic, sn-chicago; also toggles APA/other branches) |
| `iicol` | Double-column layout |
| `referee` | Double line spacing |
